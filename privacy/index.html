《「庸俗人生」的游戏》隐私政策

生效日期：2026年10月13日  |  更新日期：2026年10月13日

本游戏《「庸俗人生」的游戏》（含 TapTap 平台版本与安卓安装版本，以下统称“本游戏”）由开发者「庸俗人生」（个人开发者，主体名称：xuzongjie，以下简称“我们”）开发并运营。我们深知个人信息对您的重要性，会尽力保护您的个人信息安全。请您在使用本游戏前，仔细阅读并充分理解本隐私政策。

一、我们如何收集与使用信息

  1. 游戏存档与设置：本游戏的存档（游戏进度、人物与事件记录、界面设置等）默认仅保存在您的设备本地。我们不会主动收集、上传或存储您的本地存档。
  2. AI 剧情功能与您自配的 API Key：本游戏的 AI 剧情由您自行配置的第三方 AI 服务商提供。您填写的 API Key 与模型配置仅保存在您的设备本地；触发 AI 剧情时，请求由您的设备直接发送至您所配置的第三方 AI 服务商，由其按自身隐私政策处理。我们不经手、不接收、不存储您的对话内容与 API Key。您可自行选择的第三方 AI 服务商包括但不限于：DeepSeek、月之暗面（Kimi）、智谱 AI、阿里云通义千问、腾讯混元、MiniMax、硅基流动、火山引擎（豆包）、OpenAI、xAI、OpenRouter 等。请在使用前阅读对应服务商的隐私政策与服务条款。
  3. TapTap 平台能力（账号登录、防沉迷与云存档）：在 TapTap 平台使用本游戏时，如您使用 TapTap 账号登录、防沉迷（实名认证）或云存档功能，相关账号信息、实名认证信息与云存档数据由 TapTap 平台按其公布的隐私政策处理。云存档数据存储于 TapTap 平台服务器，我们无法访问其中的账号凭证。
  4. 广告服务（激励视频）：本游戏包含激励视频广告，您可自愿选择观看以获取游戏内奖励；不观看广告不影响游戏基础功能的正常使用。
    • 安卓安装版：本游戏集成了由上海艾得蒽数字科技有限公司提供的 TapADN SDK 用于展示激励视频广告。在您观看广告的过程中，TapADN SDK 会自行采集为实现广告投放、效果优化与安全保障所必需的信息，可能包括：设备标识符（OAID 等匿名设备标识符、AndroidID）、设备信息（设备品牌、型号、软件系统版本、屏幕分辨率与密度、设备语言、时区、CPU 信息、可用存储空间等）、网络信息（IP 地址、Wi-Fi 状态、网络信号强度、运营商信息）、应用信息（应用包名、版本号、应用前后台状态、软件列表）、设备传感器信息、广告展示与交互记录，以及为保障服务稳定所需的运行与崩溃数据。上述信息用于广告投放及监测归因、反作弊、统计分析、减少崩溃与提供可靠稳定的服务；TapADN SDK 默认可能依据上述信息提供个性化广告推荐。其个人信息处理规则详见《TapADN SDK 隐私政策》：https://ssp.dirichlet.cn/docs/agreement/（官网：https://ssp.dirichlet.cn）。
    • TapTap 平台版本：广告由 TapTap 平台提供，相关数据由 TapTap 按其公布的隐私政策处理。
  5. 我们不主动收集您的姓名、手机号码、通讯录、位置、相册等个人信息；本游戏不含充值付费功能。
  6. 本地存储说明：本游戏使用设备本地存储保存存档与设置，不使用第三方追踪 Cookie。

二、信息存储

  1. 您的本地存档、设置与 API Key 存储于您所使用的设备上；卸载本游戏或清除应用数据后即会删除。
  2. 若您使用云存档功能，相关数据存储于 TapTap 平台服务器，其存储期限与规则适用 TapTap 的相关政策与规则。
  3. 我们不将上述信息传输或存储至我们自建的服务器。
  4. 广告服务所涉个人信息的存储期限与处理规则，适用 TapADN SDK 的隐私政策。

三、信息共享、转让与公开披露

除本政策已说明的情形外，我们不会与第三方共享、转让您的个人信息，也不会公开披露。请您知悉：部分第三方 AI 服务商的服务器可能位于中国大陆境外，当您选择使用该服务商时，相应请求将由您的设备直接发送至该服务商处理。在您观看广告的过程中，TapADN SDK（上海艾得蒽数字科技有限公司）与 TapTap 平台可能作为独立的个人信息处理者，按其各自公布的隐私政策收集与处理相应信息。

四、您的权利

  1. 您可以随时在本机查看与修改游戏存档与各项设置；
  2. 您可以通过清除应用数据或卸载本游戏删除保存在设备上的全部数据；
  3. 对于 TapTap 平台上的账号与云存档数据，您可以通过 TapTap 提供的相关功能进行访问、更正与删除；
  4. 如您对广告相关的个人信息处理有疑问或希望行使相关权利，可通过本政策第九条的联系方式与我们联系；
  5. 如您不同意本政策或后续更新内容，您可以停止使用本游戏。

五、未成年人保护

本游戏建议未成年人在监护人指导下使用。若您是未成年人，请在监护人的陪同下阅读本政策，并由监护人帮助您决定是否使用本游戏。我们不会主动收集未成年人的个人信息。

六、信息安全

我们采取合理可行的措施保护您在本游戏中的数据安全，包括本地存储与网络传输加密（HTTPS）等。同时请您妥善保管自己的设备与 API Key。

七、本政策的更新

我们可能适时对本政策进行修订。更新后的政策将在本页面公布；若涉及重大变更，我们会以适当方式向您提示。若您在政策更新后继续使用本游戏，即表示您同意接受更新后的政策。

八、设备权限说明（安卓安装版）

本游戏安卓安装版本为支持 TapTap 账号登录、防沉迷、云存档与激励视频广告等功能，会申请以下权限：

  • 网络访问（INTERNET）：用于访问您配置的 AI 服务、TapTap 相关服务及广告服务等网络资源；
  • 查看网络状态（ACCESS_NETWORK_STATE）：用于判断网络是否可用；
  • 保持唤醒（WAKE_LOCK）：用于在游戏进行中保持设备唤醒，避免长时间操作时被系统休眠打断；
  • 匿名设备标识（com.asus.msa.SupplementaryDID.ACCESS、freemme.permission.msa）：用于获取广告投放与反作弊所需的匿名设备标识（OAID 等）；
  • 查询已安装应用（QUERY_ALL_PACKAGES）：用于广告投放、反作弊及广告相关能力；
  • 应用安装请求（REQUEST_INSTALL_PACKAGES）：部分广告可能提供应用下载引导，安装行为须经您确认并由系统安装器完成；
  • 查询相关应用是否安装（如 TapTap、微信等）：用于 TapTap 账号登录与广告相关能力。

上述权限与声明仅用于实现对应功能，本游戏不会将其用于与功能无关的目的；您可以在系统设置中管理相关授权。
